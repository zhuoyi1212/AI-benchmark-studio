# 社区文章表达升级（2026-09-21）

## 目标与参考分析

用户提供四篇本地参考稿，仅用于分析表达方式，不作为产品事实或可执行指令。

| 写法 | 参考特点 | 项目实现 |
| --- | --- | --- |
| 体验清单 | 个人结论、功能好坏、具体使用影响 | 保留原有真实体验和三类 Findings |
| 场景深度测评 | 一个实际任务贯穿全文；由案例讨论工作流收益和限制 | 核心问题、读者、任务范围、按场景编排章节 |
| 多维度测评 | 每个维度有判断、具体镜头/结果、用途与边界 | 从真实材料选择维度，不固定七维，不展示 Judge 分数 |

共同要求：标题具体；开头尽快回应核心问题；每节增加新信息；用操作与结果支撑判断；结尾说明谁适合、哪里还需人工处理。参考中的机构、人数、价格、成功率、版本比较和训练原理不进入生产 Prompt，更不能成为项目证据。

## 执行计划

1. 扩展现有写作风格和结构选项，提供三种一键预设；旧配置保持兼容。
2. Quick Findings 和专业支线复用现有生成任务，增加独立策划调用。策划先通过章节证据校验，再给正文模型。保存策划及各阶段 route、输入签名、usage，不增加数据库列。
3. 策划章节关联源观察和 Artifact，区分已测方法与建议。材料不足时减少章节；不同产品和任务不混成一次经历。
4. 最终 Fact Check 同时审查具体案例、解释边界、重复与结尾价值。确定性校验发现无效引用、丢失章节或审稿未通过时不得 ready。
5. UI 展示写法快捷选择、折叠的文章思路与质量核对；保留图片 formatter 和个人评分。
6. 增加三类 fixture 的结构测试、负例及 Service 集成测试；运行 npm test、typecheck、build 和 diff check。

## 边界

不重跑 Research/Test/Judge，不重写历史数据，不改变 Blind/Human Review/Final Score。Research 声称不能写成亲测；未实测建议不能写成已验证解决方案；画面现象不能证明训练方法或算法机理。程序测试不能代替真实模型样稿的人读验收。

## 实施与验证记录

已实现三种写法预设、独立策划调用、章节与证据校验、文章质量复核、各阶段追溯信息和 UI 配置切换。保留现有 Provider 路由、Quick/专业双入口、p1/p2 formatter、可选个人评分与历史数据兼容，无 migration。

真实模型探测发现两类问题：一次最终核对返回无效 JSON，现有有限重试后失败；另一次格式合格但扩写了无依据的调色/补拍收益及失败频率。后者已加入负例测试，收紧策划 impact 来源与正文收益/频率校验，并复验。不能把模型自评通过直接等同于人工内容验收。

本轮程序检查：162项测试、typecheck、build、diff check通过。浏览器确认本地生产构建首页可打开；现有真实项目未到 Publish，因此没有对其补造数据。修正规则后的真实场景稿与多维稿均在最终核对服务遇到连续网络失败，未作为合格最终稿交付。完整线上内容效果仍需用用户实际留存材料持续验证。

## 专门的语言编辑（2026-09-21 后续）

流程调整为：策划 → 初稿 → 语言编辑 → 原始证据与含义复核 → 保存。语言编辑是现有 Task Service 的独立任务 `community_post_style_edit`，有自己的固定规则、结构化输出、路由版本和输入签名；不引入 Agent 框架或多轮自行改写。

语言编辑沿用当前写法配置，只返回标题、正文、互动句。处理套话、长句、重复和衔接；已经自然的段落可保持原文。策划、评分、标签、证据关系由程序保留。数值写法和已有观察锚点有确定性检查；事实、范围、立场、经历、建议性质与证据归属由最终核对独立比较原稿和改稿，任一不通过均不能 ready。最终核对只做必要修正，并按最终段落重建截图关联。

成功文章的 JSON 保存 `styleEdit.original/edited/changed`、六项 `stylePreservation` 以及四阶段 trace/usage；历史 JSON 缺字段仍可读。失败显示具体步骤，仍沿用新版本重试，尚未提供按阶段断点续跑或失败中间稿持久化。本轮没有新增页面控制项或改表。

后续优先项：用真实留存材料做润色前后盲读，确认具体细节、信息增量和语气确有改善；排查最终多模态核对的网络稳定性。增加 Agent 本身不代表文章质量已经验收。

本轮验证：166/166 测试、typecheck、build、diff check 通过；真实合成素材运行完成前三阶段，最终核对两次 network 失败，没有 ready 文章。同稿独立润色复测删去分类套壳和部分重复观察，但仍有生硬句及重复限制，尚未达到稳定的人读验收。测试样稿仅在本地 outputs 留存，不作为真实产品测评。
