# 社区输出改进实施与验收

2026-10-17，本地实现。依据[社区文案诊断](社区文案诊断与自然表达改进方案.md)，改动集中在已有生成链路和复制输出，不新增Agent或生成阶段。

| 环节 | 实际改动 |
| --- | --- |
| 提纲 | 聚焦一个实际使用/选择问题；细节要说明对任务的影响，同一发现不拆成多个同义观点 |
| 正文输入 | 由显式字段投影构建，不重复旧selectedIdea和humanConfirmedFindings副本；完整任务及条件、事实账本、各项限制、作者输入、原始文本和确认后的Brief均保留 |
| 写作 | 少写无关参数和逐项报备；长引用只留代表性片段，解释其意义；同一结论不在结尾再讲一遍 |
| 审稿与修订 | 定位重复结论、无用参数堆积、长复述及互动重复；只修具体问题，保留不同条件和有依据的作者取舍，不强制总结或正反平衡 |
| 标题 | 保留产品、用途及具体信息，不要求冒号、三项名词或统一句式 |
| 复制全文 | 省略空的互动区块；若正文已有同一个独立互动段落，不再追加一份。只比较规范化后的相同文本，不自动删改近义句或保存稿 |

沿用Kimi K3正文/修订/标题路由及独立文本/视觉审核；受影响Prompt已升版，版本与全文同步到`docs/ai-prompt-inventory.md`。新策略版本为`community-story.v8-reader-editing`。策划和审核继续读取完整来源及原始证据；JSON结构、数值与事实门禁、截图归属、旧稿版本和失败状态规则保持。

## 验证结果

- 新增6项回归，覆盖快速/专业输入投影、真实作者输入及完整任务条件保留、一次定向去重与独立终审、空互动与复制去重、汇编内豆包历史稿的真实重复案例。
- 全仓454/454测试通过。首次发现标题提示词文档未同步，更新文档后重跑全部通过，没有关闭检查。
- typecheck、生产build（含媒体隔离自检）、diff检查通过；lint为0 errors、26条既有warnings。
- 工作区额外审计因用户此前删除的旧模板文件无法读取而停止，未恢复或撤销该删除；另从待提交内容构建隔离快照，454个文件、74个真实流程边界的Secret/客户端/Provider/Mock检查通过，并在内存中比对现有配置密钥未发现泄漏。隔离目录不包含.env文件。
- 使用真实AI Task Service、Router和Provider Adapter，仅向本地127.0.0.1的合成Provider发出5次请求，完成策划→初稿→初审→修订→终审；2次Kimi Adapter请求，保存对象通过既有最终保真校验。Repository为测试harness，没有写入数据库，也没有请求真实模型服务。这是调用链集成验证，不是模型效果评估或全产品E2E。

## 效果边界与后续验收

当前结果证明新输入契约、版本追踪、修订/终审与复制行为可用，不能证明模型自然度已经提升。本轮没有部署、运行真实新稿、替换App中的旧文章或改变实验结果，也没有迁移或新增依赖。

正式判断效果时，先以即梦、懂你AI、秘塔的相同材料生成新版本，保留旧稿；逐句检查必要事实和限制，再随机顺序比较主线、具体性、重复、自然阅读偏好及编辑修改负担。其余四例留作检验，不把23个历史版本当独立样本。真实生成和发布应单独执行并记录结果，不能用合成测试或这份实施说明代替。
