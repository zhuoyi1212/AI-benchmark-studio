# Kimi深度研究实测：3款短视频工具初筛报告

我让一个研究类AI给3人营销团队筛中文文案转短视频工具，要求是每款覆盖操作、字幕配音、动画、导出水印、价格五个维度，结论都带官方链接。Kimi深度研究一次回复给出了剪映、度加、来画三款的对比，全文1211字，末尾有选型建议。

最有价值的是它对查不到的硬限制没有硬编答案。剪映的导出分辨率、水印策略和会员价，度加的导出、水印和价格，原文都明确写了「未找到官方来源可核验」；剪映部分能力和来画的批量成片效率标了「官网宣传，未实测」。读报告时能一眼分清哪些是官方可查、哪些还得自己确认。

价格上只有来画落到了具体数字：普通会员¥398/年、无水印3次/月，Pro¥4998/年、50次/月、1080P。但报告自己提示Pro账号数为1，三人并发要确认多账号或企业版，这个单账号价不能直接当团队成本。

报告自身的未实测标记口径不完全一致：剪映和来画的部分能力标了，度加的「输入文案成片」、台词音色编辑和来画字幕配音同样取自官方页面，却没有逐项加同样的提示。这些描述有官网出处，但仍不代表实际成片效果。

这份报告适合当选型起点，能先拿到候选工具名单和待查事项。但导出、水印、价格这些决定预算的硬项，尤其剪映和度加，采购前必须按当前官方页和实际试用再核一遍。
