# 即梦AI中文咖啡市集海报实测：一轮四张，三张满版草稿

我用即梦AI免费账号里的Seedream4.0跑了一条3:4竖版海报提示词：暖米色背景、手绘插画风，下半部分是一杯拿铁、两枚咖啡豆和木桌，上方标题“周末咖啡市集”加小字“周六 10:00—18:00”。默认的5.0 Pro被会员入口拦住，就用了免费的4.0，一次出4张，我把原始PNG都下载下来看了。

四张的中文都没错字缺字，标题和时间都能读清；第二、三张标题排成两行，第一、四张是一行。

其中三张画面是填满的，拿铁还带心形拉花，标题时间在上方，构图挺规整，可以直接当活动海报草稿挑。第三张要注意：文件本身是1728×2304的3:4，但画面缩在中间，左右两条明显黑边。所以挑图时别只看文件比例，打开原图看一眼画面有没有铺满。

还有一个边界要说清：四张下载图右下角都带“即梦AI”标志，这是本账号导出带的，不是模型自己画上去的品牌。对外发布前得确认平台标识要求和发布场景是否允许。

这次只测了一条提示词、一轮四张，反映的是免费账号单次表现，不能推算整体出图成功率。
