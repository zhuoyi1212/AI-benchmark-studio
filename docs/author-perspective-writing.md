# 作者判断与自然表达

实现日期：2026-10-16。目标是让测评文章有作者真实的关注点和取舍。效果尚待真实样稿评估，工程测试只能验证输入、保存与门禁。

## 怎么使用

确认发现时展开“补充你的判断”，按需要填：这次想解决什么、最在意哪个细节、能接受什么不能接受什么、测完之后怎么选。全部选填，每项最多600字。

已有文章也可展开同一区域补充，然后点击“重新生成文章”。系统保存一个新版本，旧稿与旧判断保留。只编辑输入框不会自动保存。全部清空后重生成，表示不使用个人判断。

例如：

> 我更在意它能不能给出准备步骤，几句安慰对我帮助不大。建议具体就值得参考，但不能因此认为加薪一定成功。

这是个人取舍。不能据此补写“用了三天”“省了两小时”“加薪成功率99%”等没有原始记录的经历或结果。

## 链路与边界

`人工输入 → human_output → 新文章config → Brief / 初稿 / 初审 / 按需修订 / 最终复核 → 新版本`

- AI Findings的输出Schema不包含作者判断，模型不能代填。写作输入将偏好与事实账本分开。
- 当前确认来源可自动继承；文章级输入优先，空值表示清空。排版偏好可复用，作者判断不跨Findings沿用。
- 选材围绕作者在意的问题，篇幅随证据分配；写作保留具体措辞，避免反复免责、机械优缺点与空泛总结。
- 审核区分偏好和事实，不因观点鲜明或口语表达而要求“抹平”；原始证据、范围、数字和引用仍要核验。主观偏好不是审核豁免。
- 程序补充检查常见阿拉伯数字百分比是否出现在来源中，兼容全角写法和“百分之99”；数值归属、中文数词及其他语义仍由独立审核核对，不能据此宣称消除了幻觉。
- 沿用集中模型路由，不新增模型阶段；Prompt和输入签名升版，成功检查点不能误用旧输入。
- 重生成通过原子RPC写入新配置与队列。失败明确提示，可重试；手动改稿与AI原始输出审计保持原有区分。

## 怎么判断有没有改善

使用同一批证据与选题做三个对照：A旧提示词；B新提示词、不填作者判断；C新提示词、填写作者真实判断。A/B观察写法变化，B/C观察人工判断的增量。保持模型、参数和证据一致，记录Prompt版本与全部调用次数。

先用5个开发案例修问题，再用未参与调参的案例验证。至少覆盖：材料少、主要正向、主要负向、有明确取舍、没有作者输入。数量仅为启动方案，不代表统计显著性。

匿名打乱稿件顺序，让两名评阅者分别比较：判断是否具体、取舍是否清楚、细节是否可追溯、阅读是否自然、是否愿意原样或少改后采用。记录偏好、理由、修改时间与分歧；先独立评，再讨论分歧。

单独统计虚构经历/数字、范围越界、遗漏重要限制及审核误杀。自然度提高而事实错误增多不能视为成功。模型自评和AI检测器分数不作为“人味”的主要证明；回归通过也不等于模型效果通过。

作品集可展示：同源旧稿/新稿、本人输入、读者盲评、事实问题清单与人工修改时间。尚未实际完成的对照必须标为待验证，不填提升百分比。
