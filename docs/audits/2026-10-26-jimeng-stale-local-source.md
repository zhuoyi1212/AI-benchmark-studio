# 即梦旧材料误用

**原因：本地对照脚本读取了第1版归档，绕过当前项目数据。** 这次对照无效，不能用于评价当前图片或风格卡效果。

只读核查结果：

- 当前测试为第6版，只有1张新图，已有对应的确认发现。
- 旧4张图片均能匹配已完成的删除回执；Storage原件、预览和相关媒体缓存均不存在。
- 线上删除正常。本地另存的旧文字观察和快照没有随网页删除同步失效，被本次脚本误当成当前材料。

本轮修复仅在本地：

- 旧对照页标为失效，移除其正文展示；历史生成记录保留失效原因。
- 旧入口禁止继续调用模型，展示脚本不能覆盖失效标记。
- 新入口只读捕获当前附件和确认发现；每次模型调用前后及本地完成前重新核对版本、可用附件ID/哈希、执行记录和确认发现。任何变化立即停止，不回退旧归档。
- 网络只允许读取来源、签发下载地址与指定Provider调用；禁止DB/Storage/App写入。

已获取当前第6版单张新图，原图完整性由现有服务校验。首次重做调用被自动审批以缺少“当前图片发送至智谱”授权拦截，未执行请求。用户随后明确授权当前图片发智谱、文字交Kimi/DeepSeek并接受正常费用；未绕过审批。

授权后按现有图片路由完成[新图两版](../project-articles/2026-10-26即梦新图两版对照/两版全文.md)，444/508字。共10次实际Provider请求、9份结构化响应；模型虽通过审核，人工仍发现标志漏检和无记录作者背景，已单独标出，不手工改稿或伪报可发布。原图与确认发现在各阶段及交付前均重新核对。工程检查554项测试、typecheck、build及新增文件ESLint通过，不重认证全产品AC。

这不代表网页删除能清扫电脑或Git中的所有独立历史副本；本轮阻止的是这些副本被当作当前证据再次生成。无生产写入、部署或历史实验改写。
