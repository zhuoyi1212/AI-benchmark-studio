# AI产品评测与内容生成平台 简历项目改写

日期：2026-10-16。仅替换原简历中该项目的四项工作描述，保留项目名称、角色、时间及其他经历。

## 可直接使用的正文

- **需求与流程：**针对36氪AI测评网冷启动内容不足、人工写作成本高的问题，规划“调研-方案-实测-分析-成稿”工作流，明确方案采用、人工实测和发现确认节点，与Codex协作完成MVP上线。
- **模型策略：**拆分检索、分析、写作与视觉理解任务，配置智谱与DeepSeek模型分工，管理Prompt版本、结构化输出与调用预算。
- **效果评估：**设计测试前方案锁定、动态评分标准与匿名评审机制，关联评分理由和原始证据，保留AI原始评分与人工纠偏记录。
- **质量迭代：**基于虚构经历、数字失真、证据错引等Bad Case，迭代原文约束、事实核验与定向修订策略；设置失败状态和有限重试，保留生成版本与审核记录，避免未通过核验的内容被误存为成稿。
